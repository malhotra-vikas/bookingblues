## 5. Railway cron services (two new ones, like the existing close-stale / booking-holds)
**a. Overage reconcile — daily**, e.g. `15 6 * * *` (UTC). Bills every closed, unbilled Crew/Fleet
window: annual plans, plus monthly windows the renewal invoice missed (cancelled before renewal,
downgraded, webhook failed until the draft finalized). Old path `close-annual-windows` still works.
```bash
curl -fsS -X POST "https://api.keeprsteady.com/v1/internal/usage/reconcile-overage" -H "X-Cron-Secret: $CRON_SHARED_SECRET"
```
Expect `{"checked":N,"billed":M,"failed":0}`. `failed > 0` → Railway logs, `overage reconcile:` (error level). Idempotent.

**b. Webhook replay — every 10 min**, `*/10 * * * *`. Re-runs Stripe events that failed or were
abandoned, with backoff, until they succeed (Stripe itself gives up after ~3 days).
```bash
curl -fsS -X POST "https://api.keeprsteady.com/v1/internal/webhooks/replay" -H "X-Cron-Secret: $CRON_SHARED_SECRET"
```
Expect `{"scanned":N,"replayed":M,"failed":K}`. Repeated failures log `webhook replay keeps failing — needs a human`.

Unprocessed backlog at any time (SQL editor):
`select source, event_id, attempts, error, created_at from webhook_events where processed_at is null order by created_at;`
